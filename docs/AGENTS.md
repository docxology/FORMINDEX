## Conventions observed in this repo
- Python scripts in `Scripts/` and `Methods/`; no packaging metadata is present,
  so there is no declared test runner or lint gate.
- Generated artifacts (reports, visualizations, targeted bibliographies) are
  committed under their output directories.
- `ToDo.md` records open work items.

commands; if the owner documents them, copy them verbatim.
