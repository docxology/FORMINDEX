# Data and software availability

The FORMINDEX release [@friedman2024formindex] identifies Daniel Ari Friedman
as project author. The original reports, FORMIS inputs, converted JSON,
bibliographies and visualizations retain their locations. The repository's
MIT license applies to its code. Bibliographic records and underlying
literature retain their source attribution and applicable reuse terms.

Run `python Scripts/Verify_FORMIS_Sample.py` with the dependencies listed
in the repository's workflow guide. The check reads the tracked sample,
writes transient JSON and reports aggregate counts. Supply
`--figure output/figures/formis-sample-types.png` to regenerate the chart.
The rendering guide records the pinned renderer and output paths.
