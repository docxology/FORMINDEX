# Introduction

FORMIS is a bibliographic resource for ant literature. FORMINDEX was developed
to read the July 2024 export, inspect publication trends and co-authorship, and
assemble narrower bibliographies for taxa, subjects and places. The first October report credits Sanford Porter for supplying the test
exports and describes the initial ingestion and visualization work. The
follow-up report describes applying the scripts to the full export and topic subsets
such as Foraging [@friedman2024oct08; @friedman2024oct13].

The project also explored machine-generated summaries, translations and
audio. These outputs remain inspectable alongside the dated reports and
figures [@friedman2024formindex]. Here we ask whether the checked-in sample
reproduces the expected processing and reveals artifacts of the matching rule.
